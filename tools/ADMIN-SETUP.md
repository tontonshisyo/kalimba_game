# 管理画面とβ版意見箱の初回設定

新しい曲を収録するには、管理画面にログインし、「共有リンクから曲を登録」にゲームの共有リンク（投稿文ごとでも可）を貼り付けます。「リンクを確認」で曲名・BPM・調号・拍子・音符数を確認し、公開状態を選んで「確認した曲を登録」を押してください。同じ曲の二重登録は拒否されます。公開した曲はゲームの再読み込みで反映されます。登録後の公開状態は「収録曲の公開設定」から変更できます。

現在の管理画面には「収録曲の公開設定」「意見箱・非公開のお問い合わせ」「管理データをバックアップ」があります。エーデルワイスは非公開で保存済みです。公開状態の変更は利用者がページを再読み込みすると反映されます。以前に保存・共有された譜面や配布済みのコピーを遠隔削除する機能ではありません。

お問い合わせは意見箱と同じテーブルに `is_public=false` で保存され、管理者のみ閲覧できます。返信欄は管理者の対応メモとして使えます。連絡先が記載されていれば、必要に応じて別途連絡してください。メールを自動送信する機能はありません。

「管理データをバックアップ」は収録曲と意見箱・お問い合わせの全件をJSONに書き出します。個人情報や非公開曲が含まれるのでGitHubに置かず、アクセスを制限した場所へ保管してください。

1. SupabaseのSQL Editorで `admin-feedback-schema.sql` 全文を実行します。
2. SupabaseのAuthentication → Usersから管理用ユーザーを作成します。メールアドレス・パスワードを設定し、メール確認済み（Auto Confirm）にします。これはSupabase Dashboardへのログインとは別の、ゲーム管理用アカウントです。
3. 作成したユーザーのUID（UUID）をコピーし、次のSQLを実行します。`ここにUID` を実際の値に置き換えます。

```sql
insert into public.otoiro_admins (user_id)
values ('ここにUID')
on conflict do nothing;
```

管理画面は、PCの `tools/open-admin.url` をダブルクリックして開きます。ブラウザーのブックマークにも保存できます。直接開くURLは `https://tontonshisyo.github.io/kalimba_game/manage-7a3d9c2e.html` です。手順2のメールアドレスとパスワードでログインします。ゲーム本体には管理画面へのリンクを表示しません。URLを知っているだけではデータを管理できず、データベース側で管理者登録を確認します。旧URLの `admin.html` は配信しません。

「投稿された曲」または「β版の意見箱」を選び、対象の「このデータを削除」を押して確認すると、その1件を完全に削除します。元には戻せません。削除した曲は、ゲームの「曲を読み込む」で一覧を更新すると消えます。すでに他の端末へ読み込まれている曲や、ファイルとして保存されたコピーは消せません。

ログイン情報とセッションはブラウザーの保存領域へ書き込みません。再読み込み・有効期限切れの際は再ログインします。管理権限を取り消す場合は、SupabaseのTable Editorで `otoiro_admins` の対象ユーザー行を削除します。

公開型の意見箱を使うには、追加で `public-feedback-schema.sql` 全文をSQL Editorで実行します。実行前に受け付けた意見は非公開のままです。新しい画面では公開確認にチェックした意見が公開されます。管理画面で「検討中・実装予定・実装済み」と返信を保存できます。公開された意見への返信も公開されます。利用者には返信の書き換え・対応状況の変更・削除を許可しません。
