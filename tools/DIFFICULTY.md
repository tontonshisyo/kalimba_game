# 曲の難易度

曲選択はカード形式です。曲名・BPM・音符数・平均音符密度・4段階の難易度を表示します。
曲名検索と難易度の絞り込みに対応し、作成・読み込み・共有リンクで受け取った曲も同じ基準で判定します。

難易度は保存データを変更せず、その曲の元のテンポから計算します。
練習モードの速度・ノーツの流れる速さ・アルペジオ用の表示時刻の補正は計算に含めません。

- 時刻（秒） = 譜面のstep × 30 / BPM（stepは半拍単位）
- 演奏区間 = 最初の音〜最後の音 + 1拍。冒頭の無音で難易度が下がらないようにします。
- 平均密度 = 音符数 / 演奏区間の秒数
- 最大密度 = 最も音符が多い連続4秒間の音符数 / 4秒。4秒未満の曲は演奏区間の秒数で割ります。
- 指標 = 平均密度 × 0.65 + 最大密度 × 0.35

| 指標 | 難易度 |
| --- | --- |
| 3.0未満 | かんたん |
| 3.0以上、3.6未満 | ふつう |
| 3.6以上、5.0未満 | むずかしい |
| 5.0以上 | めちゃむず |

現在の「大きな古時計」（BPM 90、137音）は平均約3.31音/秒、最大5.0音/秒、指標約3.90で「むずかしい」です。
同じ拍の和音は構成音をそれぞれ数えます。指の移動距離などは含めていないため、難易度は音符密度に基づく目安です。
