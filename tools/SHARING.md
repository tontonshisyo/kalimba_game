# 曲の作成とSNSリンク共有

## 演奏結果の画像共有

演奏が終了すると、リザルトに「画像を共有」「画像を保存」とプレビューを表示します。
曲名・得点・PERFECT/GOOD/MISS・最高コンボ・タイミング・演奏モード・BPMを1200×1200pxのPNGにまとめます。
ファイル共有に対応する端末では共有メニューを開き、未対応なら画像を保存してSNSへ投稿できます。
曲名・得点・サイトURL・ハッシュタグを含む投稿コメントを自動で用意し、編集・コピー・例文への復元ができます。
「画像とコメントを共有」は画像と空でないコメントをセットで渡します。空欄の場合は共有を止めます。
SNSアプリが文章を省略すること自体は制御できません。その場合は「コメントをコピー」で貼り付けてください。
「コメント付きでXを開く」は本文入りの投稿画面を開きます。画像は「画像を保存」で保存したものをX側で添付してください。Web投稿画面へローカル画像を自動添付する処理は行いません。
画像は端末内だけで生成し、曲の譜面やサーバーへのアップロードは含めません。自動投稿はしません。
保存できない場合はプレビュー画像を開いて長押しで保存できます。画像生成に失敗した場合は再作成できます。

曲の一般公開一覧・サーバー投稿は廃止したまま、SNSやメッセージに貼れる共有リンクを使います。

1. 「曲の作成・共有」で曲を編集します。
2. 「共有リンクを作成」を押します。
3. 「SNSなどに共有」（対応端末のみ）または「リンクをコピー」で渡します。
4. 受け取った人はリンクを開き、「この曲を演奏」を押します。ファイル操作は不要です。
5. 「この端末に保存」で、受け取った曲をブラウザー内に残せます。リンクを開くだけでは保存も音声再生も行いません。

曲名・テンポ・調号・音符をURLの #song= 以降に含めます。この部分はサイトへのHTTPリクエストには含まれず、曲の保存APIも使いません。
リンクをSNSに投稿すれば、そのリンクを知っている人が曲を開けます。暗号化やアクセス制限のある共有ではありません。

音符の位置の差分と鍵盤番号を可変長整数にし、短くなる場合はgzipも使います。
細かな小数がある譜面は、タイミングの精度を保持する形式に切り替えます。
リンクは最大8000文字です。2000文字を超える場合は末尾の欠落に注意する案内を表示します。長さは曲の内容により変わり、SNSごとの制限もあるため、長い曲は分割してください。
復元後は既存の譜面検証を行い、1〜2000音・位置・音高・調号などを確認します。展開サイズは2MBまでです。

以前の .otoiro / JSON ファイルは「以前の共有ファイルを読み込む」から開けます。
保存曲はこのブラウザー内にあり、ブラウザーのデータを消すと消えます。

以前の投稿データは削除せず、管理者専用RLSを残して一般閲覧と投稿を停止しています。
再設定には tools/community-sharing-only.sql を使用します。意見箱の公開・返信機能は継続します。

## フリー演奏の動画

フリー演奏で録音を停止すると「動画を作成」を選べます。開始・終了の秒数で最長60秒の演奏範囲を切り出し、約3秒の余韻を付けた720×900の動画にします。録音時の各音の音程とタイミングを使い、鍵盤から上へ流れる音符を描きます。音声は端末内のOfflineAudioContextで合成し、canvas.captureStreamとMediaRecorderで映像・音声をまとめます。カメラ・マイク・動画アップロードは使いません。

MP4を優先し、非対応ならWebMを選びます。作成は動画と同じ程度の時間がかかります。中止・画面を離れる・ダイアログを閉じると録画を止め、音声ノード・トラック・AudioContextを解放します。元の録音は残します。非対応ブラウザーには作成不可を案内します。

完成後はプレビュー・保存・対応端末でのコメント付き共有ができます。共有はユーザーのボタン操作時だけ実行します。SNSによって受け入れる動画形式やコメントの扱いが異なるため、動画保存とコメントコピーも用意しています。録音と生成動画はページ内の一時データなので、残す動画は保存してください。
