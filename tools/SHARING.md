# 曲の作成とファイル共有

曲の一般公開・投稿は廃止しました。作成・読み込み・削除はブラウザー内だけで行い、曲をサーバーへ送信しません。

1. 「曲の作成・共有」で曲名、テンポ、調号、音符を編集します。
2. 「この端末に新しい曲を保存」で、このブラウザーの曲一覧に追加します。
3. 「共有ファイルを作成」で、編集中の1曲を .otoiro ファイルにします。
4. 「共有先を選ぶ」（対応端末のみ）または「ファイルを保存」で渡します。
5. 受け取った人は同じサイトの「共有ファイルを読み込む」で追加して演奏できます。

共有ファイルには曲名・テンポ・調号・音符だけを含めます。全曲の一括送信や公開URLの作成はしません。
対応ブラウザーではgzipで圧縮し、未対応なら同じ拡張子の非圧縮ファイルを作成します。従来のJSON譜面も読み込めます。
読み込み・展開後とも2MBを上限とし、既存の譜面検証を通してから保存します。
ブラウザーのデータを消すと保存曲も消えるため、必要な曲は共有ファイルとして保管してください。

既存の投稿データは削除せず、管理者専用RLSを残して一般閲覧と投稿を停止しています。
再設定には tools/community-sharing-only.sql を使用してください。
旧 community-schema.sql も公開を再開しない設定に変更済みです。意見箱の公開・返信機能は継続します。
