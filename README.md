# OTOIRO — カリンバ・リズムゲーム

# 曲の共有について

曲の一般公開・投稿は廃止し、ブラウザー内での作成・保存とSNSに貼れるリンク共有に変更しました。
「共有リンクを作成」で編集中の1曲を圧縮したURLにし、受け取った人はリンクを開いて演奏できます。以前の .otoiro / JSON ファイルも読み込めます。共有文には #おといろ #カリンバ #音ゲー が含まれ、不足するタグは共有時に補われます。
作成・読み込み・削除は端末内だけで行い、プロジェクトの公開譜面ファイルやサーバーへ自動保存しません。
詳しくは [共有の説明](tools/SHARING.md) を参照してください。以下の旧フォルダー連携の説明は開発用の手動操作です。

「フリー演奏」ボタンで、譜面・判定・スコアなしの演奏画面に入れます。17鍵をタッチ・スライド・PCキーボード（1〜0、Q〜U）で自由に弾けます。音色・音量・鍵盤の色マークは設定を引き継ぎます。「フリー演奏を終了」で曲選択画面に戻ります。

フリー演奏では、弾いた鍵盤の位置からレーンに沿って音符が上へ流れます。音符は約1.8秒かけて小さく薄くなり、消えます。

「フリー演奏の調」では3方式を選べます。①調号のみ：ドレミの配置を保ち、15種類の長調の調号に合わせて♯・♭を付けます。②最低音を変更：中央の鍵盤をC3〜B4の音へ移し、音程間隔を保って全体を移調します。③個別調整：C調を基準に各鍵盤を±12半音まで、1半音ずつ上下できます。演奏前・フリー演奏中のどちらでも変更でき、調整後の音名を鍵盤に表示します。選択した設定はブラウザー内に自動保存します。「標準のC調に戻す」で全方式の設定をリセットします。通常の譜面・練習モードには適用しません。

スマートフォンのブラウザーで遊べる、タッチ操作対応の標準17鍵カリンバ練習ゲームです。追加のビルドやパッケージのインストールは不要です。

17個の鍵盤は実機の並びに合わせ、左端のD6から中央のC4を挟んで右端のE6へ並びます。スマートフォンでは横画面にすると鍵盤を広く表示して演奏できます。

曲を選ぶ間は鍵盤と譜面を隠し、「演奏をはじめる」を押すとプレイ画面に切り替わります。演奏中は鍵盤・奥行きのあるノーツレーン・コンボ・判定に集中できます。曲のBPMは譜面どおりに保ち、ノーツの移動時間だけを調整しています。ノーツは鍵盤と同じ位置に向かって台形レーン上を流れます。

曲選択画面で「練習モード」を選ぶと、ノーツが判定位置で止まり、対象の音を弾くまで次へ進みません。判定位置に来る前の音やタイミングが違う入力でも、練習モードでは失敗になりません。同じ拍の和音は左右の手にかかわらず低い音から高い音へ最大0.06秒間隔で並び、和音全体の長さは最大0.3秒ですが、練習モードではGOODの判定範囲内にある同じ和音の音を好きな順で弾けます。譜面データ自体の拍や音は変更しません。中央のC4は同じ拍で音数が少ない手に割り当てます（同数なら左手）。通常プレイでは従来どおり、タイミング判定とミスが有効です。

練習モードを選ぶと表示される「開始する拍」で、練習を始める位置を指定できます。譜面の拍数（0拍から）を入力すると、その拍より前のノーツを飛ばして再生します。製作者モードの「テスト開始拍」も同様に、編集中の譜面の指定拍以降をテストできます。音がない拍を指定した場合は、譜面の範囲内に修正するよう案内します。

曲選択画面の「演奏の設定」から、音量（初期値100%）、ノーツの流れる速さ（初期値100%）、練習モード時の曲の速さ（初期値100%）を調整できます。設定はブラウザー内に保存されます。ノーツ速度は曲のリズムを変えずに移動時間だけを調整し、曲の速さは練習モードでのみ譜面のテンポを変えます。

演奏中は一時停止でき、一時停止画面の「演奏をやめる」で曲選択画面に戻れます。やめた場合は途中の譜面を破棄し、曲や設定を選び直せます。

「演奏の設定」の「鍵盤の色マーク」で、交互（赤・青）、1本おき、ドだけ、ドとファ、左右の手、音名ごとの7色から選べます。「なし」で目印を消せます。設定画面に実際の17鍵と同じ並びの見本を表示し、選択はブラウザーに保存します。鍵盤上部の色帯は、演奏中の光るガイドと併用できます。

音色は、短い弾き始めの音・金属的な響き・低音ほど長い余韻を重ねたカリンバ風の合成音です。全音で共用する控えめな残響と、和音の音量の膨らみを抑える処理を加えています。

## 製作者モード

「曲の調号」で15種類の長調の調号を選べます。鍵盤のドレミの配置・オクターブを保ち、対象の音だけを半音上下します。譜面欄は元の自然音名（例：F4）のまま入力し、ト長調ならF4がF♯4として鳴ります。五線譜には対象音の♯・♭を表示し、試聴・録音・テストプレイ・通常プレイ・練習モードにも反映します。調号は曲と一緒に保存・共有・JSON書き出しされます。調号のない既存データはハ長調として読み込みます。フリー演奏の調設定とは独立しています。

「譜面を並べ替える」を押すと、入力欄を拍の昇順・同じ拍なら低い音順に揃えます。音符につけた行末のコメントも一緒に移動し、空行と独立したコメントは残します。不正な入力がある場合は変更せずエラーを表示します。並べ替え後は保存ボタンで保存してください。

五線譜の空白をタップすると、その位置の拍・音高に音符を追加します。既存の音符をタップすると削除し、ドラッグすると拍と音高を変更できます。入力単位は1拍・0.5拍・0.25拍から選択します。右端には次の音を追加する余白があります。編集は下の譜面欄に反映され、保存ボタンを押すまで保存されません。横スクロールだけでは音符を追加しません。音符にフォーカスしてDelete・Backspace・Enter・スペースでも削除できます。

演奏中の鍵盤ガイドは、次の拍にある和音の構成音をまとめて光らせます。アルペジオで表示時刻がずれた音も元の拍でまとめ、弾き終えた音からガイドの光が消えます。

練習モードでは、同じ和音の音を順不同で入力できますが、判定は各ノーツの表示時刻に対して前後0.2秒（GOODの範囲）以内に限ります。待機中は停止時刻を基準に判定します。まだ範囲外の音が残る場合は、そこまでノーツが進んでから再び待機します。対象外の鍵盤も音は鳴りますが、譜面の判定は進みません。

譜面は保存・読み込み時に拍の昇順、同じ拍の中では音の高さの昇順に並べます。保存済みのブラウザー内の譜面も起動時に同じ順へ揃えます。並び順のみ変更し、音や拍の値は変更しません。

曲選択画面の「製作者モード — 譜面を作る・編集する」を開き、拍と音名を1行ずつ入力します。形式は `拍,音名` です（例: `0,C4`）。拍はBPMに対する四分音符の拍数で、小数も使えます。同じ拍で左右に1音ずつ指定すると同時に演奏します。同じ手の複数音は低い音から高い音へアルペジオで演奏し、各手の一番高い音が指定拍に合います。入力欄の上には五線譜プレビューが表示され、横軸に0からの拍、縦軸にト音記号での音高を示します。各拍は等間隔に配置し、同じ拍の音は横にずらさず縦に並べます。音符はタイミングを見やすくするため丸だけで表示します。譜面が長い場合は横スクロールできます。入力の途中で形式が不完全な行があっても、有効な音はプレビューに表示されます。空行と `#` 以降のコメントは無視されます。

「選択中の曲を読み込む」で譜面を呼び出し、「選択中の曲に保存」で既存曲を上書きできます。「新しい曲として保存」で自作曲を追加し、選択中の自作曲は削除もできます。通常の保存先はブラウザーのローカル保存領域なので、ページ更新では消えませんが、ブラウザーのデータ消去や別端末への移行では引き継がれません。BPMは30〜240、音名は標準17鍵の範囲から選択します。

プロジェクトの譜面ファイルへ保存するには、まずPC版ChromeまたはEdgeでLive ServerのURL `http://127.0.0.1:5500/` を開いてください。`file:///.../index.html` を直接開いた画面では、ブラウザーの保存領域とスマホ配信側が別扱いになるため連携できません。Live Server画面で「スマホ用譜面の保存先を設定・確認」を押し、`index.html` が入っている一番外側の `program_1022` フォルダー（目安：OneDrive → デスクトップ → program_1022）を選択します。フォルダーを選んだ後に書き込み許可を求められた場合は許可してください。`assets` や `data` フォルダーではなく、Live Serverで開いているゲームと同じプロジェクトのルートを選んでください。曲データを `assets/data/custom-charts.json` に保存し、Live Serverが実際に配信しているデータと一致するかも自動確認します。一致しない保存先を選ぶとエラーを表示するため、その場合は公開中のプロジェクトフォルダーを選び直してください。Live Serverは譜面JSONの更新ではページを自動再読み込みしない設定です。連携後は同じPC・ブラウザーからの曲の追加・編集・削除時に同ファイルも更新され、スマートフォンでページを再読み込みすれば新しい曲を選べます。`.vscode/settings.json` のLive Server設定を反映するため、設定変更後はLive Serverを一度停止して起動し直してください。プロジェクトファイルをGitなどに含めれば、ソースと一緒に保管・共有できます。

「譜面を試聴」は入力中の譜面をBPMに合わせて自動演奏し、「テストプレイ」は保存せずにノーツを流して操作・判定を試せます。試聴・再生でも左右の音は同時に鳴り、同じ手の複数音だけ低い音から高い音へ最大0.06秒間隔（片手最大0.3秒）で並びます。各手の一番高い音の判定が譜面の拍に合います。テストプレイは開始拍と練習モードの設定にも対応し、一時停止後に「テストを終了」すると編集画面へ戻ります。試聴・テストプレイの内容は保存操作をするまで譜面データに反映されません。

「鍵盤で録音」では、曲のBPMと4分・8分・16分音符のクオンタイズを選び、メトロノームの1小節カウントインに続けて鍵盤を演奏します。録音を止めると、入力した音を譜面欄へ反映します（同じ拍の同じ鍵盤は重複記録しません）。録音内容は自動保存されないため、確認後に既存曲へ保存するか、新しい曲として保存してください。録音中にページを離れた場合は録音を終了します。

「譜面データを書き出す」で内蔵曲・編集済みの曲・自作曲をJSONファイルに保存できます。別のブラウザーでは「譜面データを読み込む」からJSONを選んで取り込めます。読み込みは現在の曲と統合し、同じ曲IDがある場合は確認のうえファイル側で上書きします。編集中の未保存テキストは読み込み後も保持されます。形式が不正な譜面が含まれている場合は、データを変更せずに読み込みを中止します。

## スマートフォンで遊ぶ

PCのサーバーを起動し続けずに遊ぶには、PCでゲームを開いて製作者モードの「スマホ用アプリを書き出す」を押します。保存された `otoiro-mobile.html` にはゲーム・音・書き出し時点の譜面が入っています。このHTMLをAirDrop、USB、クラウドストレージなどでスマートフォンへ渡し、端末のブラウザーで開けば、以後PCの電源やサーバーに接続せずプレイできます。新しい譜面を追加したら、もう一度書き出してスマートフォンへ渡してください。リポジトリーから手動で作り直す場合は `tools/build-mobile.ps1` を実行します（この方法は `assets/data/custom-charts.json` の曲を含みます）。iPhoneではファイルの開き方によってプレビュー表示になり、ゲームが動かないことがあります。その場合はHTTPSのWebサイトとして一度開く方法を使ってください。

既存の同じWi-Fi経由で遊ぶ方法も使えます。譜面ファイルを更新しながらPCから配信する場合は、以下の手順を使ってください。

1. PCとスマートフォンを同じWi-Fiに接続します。
2. VS Codeでこのフォルダーを開き、推奨拡張機能の **Live Server** をインストールします。
3. `index.html` を右クリックし、**Open with Live Server** を選びます。
4. PCで `ipconfig` を実行し、Wi-Fiアダプターの「IPv4 アドレス」を確認します。
5. スマートフォンのブラウザーで `http://PCのIPv4アドレス:5500` を開きます（例: `http://192.168.1.20:5500`）。
6. 「演奏をはじめる」をタップし、画面下の音階キーをタップして演奏します。

`.vscode/settings.json` はLive Serverを同じネットワークから開けるように設定しています。接続できない場合は、PCのファイアウォールでプライベートネットワーク上のLive Server通信を許可してください。この方法ではプレイ中もPCとLive Serverが必要です。

## ホーム画面への追加・オフライン利用

練習モードでは判定対象になった音を順不同で入力でき、弾くまで待機します。待機中もタッチのエフェクトは実時間で動き、譜面の停止時刻とは別に管理します。スマートフォンで画面更新が遅れた場合も、タッチ時に待機状態を更新します。

オンライン時は最新のファイルを確認し、通信できない場合は保存済みのファイルを使います。以前の版がスマートフォンに残っている場合は、オンラインでページを開き、数秒待ってから再読み込みしてください。

`manifest.webmanifest` と `service-worker.js` を含み、HTTPSで配信するとホーム画面への追加とオフライン起動に対応します。ローカルWi-Fi上のHTTP接続はゲームのプレイには使えますが、ブラウザーの制約によりオフラインキャッシュやPWAインストールが有効にならないことがあります。

## GitHub Pagesで公開する

このプロジェクトには `.github/workflows/pages.yml` を含み、GitHubリポジトリの `main` または `master` ブランチへ反映すると、GitHub Pagesへ自動公開できます。リポジトリの Settings → Pages で公開元に「GitHub Actions」を選び、初回のActions実行が完了すると表示されるURLをスマートフォンで開いてください。HTTPSで最初に開けば、ホーム画面への追加と、初回読み込み後のオフライン起動も利用できます。公開リポジトリを使う場合、ゲームのソースと同梱譜面も誰でも閲覧できます。
